## Branded Mac app and desktop batch

Beta 2 adds the complete branded LocalOCR application icon to the signed Mac
app and Finder. LocalOCR Studio still opens with one document at a time. Open
or drop a PDF or supported image to use the familiar single-document path.
Choose **New Batch** only when you want a review-first group workflow.

In **New Batch**, add files or folders and choose the output folder before
starting. Folder selection scans recursively for supported PDFs and images.
Studio presents supported and skipped items for review; adding a selection does
not start OCR. After review, **Start Batch** processes the queue sequentially,
one document at a time.

Every batch output stays under the folder you chose. PDFs produce a new
searchable PDF; images produce a `.txt` file with recognized text. Source files
are unchanged. Studio never overwrites an existing output; it uses a numbered
name when the preferred output name is occupied. At completion, use **Retry
Failed**, **Reveal Output Folder**, or **Start New Batch**. You can return to
**Single Document** when no batch is processing.

## Privacy

LocalOCR is 100% local. Apple Vision recognition, PDF processing, input review,
and output writing happen on the Mac. The app does not upload document content,
recognized text, filenames, paths, thumbnails, hashes, cache entries, or
outputs. The CLI and MCP server are advanced local-use interfaces; MCP uses
local stdio and has no HTTP or network transport.

User-selectable Apple Foundation Models, Ollama, and LM Studio support is
next-version work and is not included in this download.

The release was built with stable Xcode 26.6 (`17F113`), Swift 6, and arm64,
with deployment target macOS 14.0. It is Developer ID signed with Hardened
Runtime, Apple notarized under accepted submission
`18581332-be97-4713-bf1d-3c2764afdfa5`, stapled, and Gatekeeper accepted.
The public downloaded package verifier passed on the build Mac (Mac17,3)
running macOS 27.0 beta build `26A5421a`. Exact-build second-Mac acceptance
passed on Scott’s Mac mini running the same macOS version and build, including
checksum, signature, staple, Gatekeeper, CLI version, MCP initialization,
installation, and launch.

Future Apple beta compatibility is not guaranteed.

## Current limitations

- No Intel, Windows, or Linux support.
- The default remains one-document processing; batch processing is an explicit
  review-before-start workflow.
- There is no batch run history, language/settings wizard, guided MCP setup,
  or local-intelligence provider selection in this build.
- OCR may need review for difficult source material; keep original documents.
