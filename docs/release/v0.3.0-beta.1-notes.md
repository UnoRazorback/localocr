# LocalOCR Studio v0.3.0-beta.1 candidate

`v0.3.0-beta.1` is a release candidate for LocalOCR Studio version `0.3.0`,
build `2`. It is not yet published. It has no release archive, checksum,
signature, notarization, stapling, Gatekeeper result, or acceptance record.
The currently published prerelease remains
[`v0.2.0-beta.1`](https://github.com/UnoRazorback/localocr/releases/tag/v0.2.0-beta.1).

## Desktop batch, after the default single-document flow

LocalOCR Studio still opens with one document at a time. Open or drop a PDF or
supported image to use the familiar single-document path. Choose **New Batch**
only when you want a review-first group workflow.

In **New Batch**, add files or folders and choose the output folder before
starting. Folder selection scans recursively for supported PDFs and images.
Studio presents the supported and skipped items for review; adding a selection
does not start OCR. After review, **Start Batch** processes the queue
sequentially, one document at a time.

Every batch output stays under the folder you chose. PDFs produce a new
searchable PDF; images produce a `.txt` file with recognized text. Source files
are unchanged. Studio does not overwrite an existing output: it uses a numbered
name when the preferred output name is already occupied.

While a batch is running, use **Cancel Batch** to stop pending work. Completed
outputs remain in the selected output folder. At completion, use **Retry
Failed** for failed items only, **Reveal Output Folder** to open the selected
destination, or **Start New Batch** to clear the queue. You can return to **Single
Document** when no batch is processing.

## Privacy

LocalOCR is 100% local. Apple Vision recognition, PDF processing, input review,
and output writing happen on the Mac. The app does not upload document content,
recognized text, filenames, paths, thumbnails, hashes, cache entries, or
outputs. The CLI and MCP server are advanced local-use interfaces; MCP uses
local stdio and has no HTTP or network transport.

## Compatibility and verification boundary

macOS 14.0+ on Apple silicon is supported by this candidate's project target.
This statement does not establish a built, signed, notarized, or accepted
candidate. The dated macOS 27 beta acceptance evidence belongs to the published
Beta 1 release only; it is not evidence for this candidate. Future Apple beta compatibility is not guaranteed.

## Current limitations

- No Intel, Windows, or Linux support.
- The default remains one-document processing; batch processing is an explicit
  review-before-start workflow.
- There is no batch run history, language/settings wizard, or guided MCP setup.
- OCR may need review for difficult source material; keep original documents.
